# Visualizations

This folder contains the visualizations created from the project's research dataset.

## Charts

- **[Country and Primary Sector](country_sector.png)** — Shows the distribution of projects by country and primary sector.
- **[Country and Financial Type](financial_type.png)** — Shows how the selected projects are classified by country and financial structure.
- **[Primary Sector Distribution](primary_sector.png)** — Shows the number of selected projects by primary sector.

## Data Source

All visualizations are based on the 10-project dataset contained in the `data/` folder.

Because the dataset is a purposively selected sample, these charts describe the selected cases rather than representing all South Korean investment or development activity in the three countries.
