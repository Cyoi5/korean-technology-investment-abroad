# Project Data

This folder contains the dataset used for the **Korean Technology, Investment & Development Cooperation Abroad** project.

## Dataset

- **[View dataset (CSV)](korean_projects_dataset.csv)** — browser-readable version of the 10-project dataset
- **[Download Excel workbook](korean_projects_dataset.xlsx)** — full workbook containing the dataset, pivot tables, and charts

## Dataset Scope

The dataset contains **10 documented projects** involving South Korean companies or organizations across:

- El Salvador
- Mexico
- United States

Each project is coded by country, organization, sector, project type, year, investment amount where available, technology focus, local partners, financial structure, and source information.

## Notes

The dataset is a **purposively selected sample** for exploratory analysis. It is not intended to represent all South Korean investment, development cooperation, or technology activity in these countries.

Investment amounts are left blank where a reliable project-specific amount could not be established from the cited sources.
